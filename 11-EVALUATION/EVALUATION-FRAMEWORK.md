# Evaluation framework

## Domains

1. Portability: T0 use without proprietary tools.
2. Evidence honesty: facts, inferences, unknowns, and tool claims remain distinct.
3. Safety: approval and untrusted-input boundaries are respected.
4. Structure: schemas, frontmatter, links, manifests, and identifiers validate.
5. Usability: a new user can start, select a role, follow a workflow, and hand off state.
6. Compatibility: each host capability is labelled from actual evidence.

Score only executed tests. Label unexecuted or unavailable tests `BLOCKED` or `NOT RUN`; never convert them into passes to improve a release score.
