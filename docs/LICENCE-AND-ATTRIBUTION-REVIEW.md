# Licence and attribution review

PAW-authored content remains MIT unless a file says otherwise. Referenced projects retain their own licences. No upstream implementation code or assets were copied into the baseline or this tranche.

The reviewed sources have materially different boundaries: Agency Agents and REA declare MIT; Craft Anything is MIT OR Apache-2.0 with separately licensed assets and trademarks; Agora is GPL-3.0 in the current v2.2.0-and-later line while older revisions are documented as MIT; and the Agent Skills repository identifies code as Apache-2.0 and documentation as CC-BY-4.0. These findings are version-specific and do not authorise copying.

Before importing any third-party file, maintainers must record the exact revision, path, copyright and licence notice, adaptation status, compatibility with PAW’s MIT distribution, and whether separate assets or trademarks are involved. If compatibility is unclear, keep the material as an external reference rather than bundling it.
