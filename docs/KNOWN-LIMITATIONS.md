# Known limitations

- The eight platform adapters are documented but not live-tested in this repository.
- The written agent and skill specifications are not proof that a host executed them independently.
- The optional validator checks structure and selected metadata, not semantic quality, model behaviour, privacy, or legal compliance.
- Native reverse engineering, MCP, scheduling, local inference, and runtime capture remain optional integrations and are not bundled.
- The baseline package contains extra legacy agent roles beyond the 46 mandatory v1 roles; they are preserved for provenance and are not counted as additional mandatory roles.
- Link checking, full schema-instance validation, manual usability testing, and evaluation coverage for every role remain incomplete.
- No v1.0.0 tag or GitHub release has been created because release gates remain open.
