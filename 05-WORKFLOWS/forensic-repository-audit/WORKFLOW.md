# Workflow: forensic repository audit

**Inputs:** canonical repository URL, audit objective, authorization, desired depth.
**Output:** evidence-based audit report and source-to-feature traceability matrix.

1. Intake and scope confirmation.
2. Repository identity and revision verification.
3. Structure and documentation inventory.
4. Source/module and feature mapping.
5. Dependency/runtime/compute analysis.
6. Security/privacy/license review.
7. Test and release evidence review.
8. Findings classification and traceability.
9. Independent QA pass.
10. Final report and unresolved-gap register.

Every phase must have an artifact and completion condition. If source files are inaccessible, report the limitation and do not imply a full source audit.
