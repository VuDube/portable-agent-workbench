# Workflow: product development

1. Intake: objective, users, constraints and success metrics.
2. Discover: research, competitive/context analysis and user evidence.
3. Specify: requirements, scope, design contract and acceptance criteria.
4. Architect: components, interfaces, data, security and operational model.
5. Plan: work packages, dependencies, risks and deliverables.
6. Build: implement using available tools and permissions.
7. Verify: functional, usability, accessibility, security and performance checks as feasible.
8. Refine: fix and retest defects.
9. Release: user approval, documentation, versioning and rollback/maintenance plan.
10. Handover: artifacts, evidence, limitations and project state.
