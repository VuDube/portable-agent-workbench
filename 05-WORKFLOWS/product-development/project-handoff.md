# Project handoff

**Capability tier:** T0/T1

## Inputs
current state, evidence, next objective.

## Steps
summarise state → attach artefacts → list decisions/unknowns → define next action → confirm recipient capability. At each step, record the actual capability used, evidence IDs, and any blocked work.

## Outputs
portable handoff packet.

## Approval gates
Require explicit approval for destructive actions, external publication, credential use, sensitive export, financial/legal submissions, or runtime side effects.

## Exit criteria
The output is traceable, limitations are disclosed, failed and blocked checks are not marked passed, and another host can resume from the recorded state.
