# Code of Conduct

Participants in the Portable Agent Workbench project are expected to be respectful, specific, and safety-conscious. Harassment, discrimination, doxxing, credential disclosure, malicious repository manipulation, and deliberate fabrication of evidence are not acceptable.

Maintainers may remove content or suspend participation when necessary to protect contributors, users, or the integrity of the project. Report concerns privately through the security contact route in [SECURITY.md](SECURITY.md).
