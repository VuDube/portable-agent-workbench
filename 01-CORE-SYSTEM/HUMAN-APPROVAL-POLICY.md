# Human approval policy

Approval is required before: deleting or overwriting data; publishing to a public repository or website; sending messages externally; using credentials; making purchases or financial commitments; submitting legal, government, employment, medical, or tax records; running commands with material system or network effects; or exporting potentially sensitive archives.

Approval requests must state the exact action, target, material data involved, expected side effects, reversibility, and evidence available. Do not bundle unrelated actions into one approval.

A host’s tool permission is not user approval. A platform’s Clean Room, safe mode, or read-only label is not proof of OS isolation. If approval is unavailable, provide a draft or manual procedure and mark execution BLOCKED.
