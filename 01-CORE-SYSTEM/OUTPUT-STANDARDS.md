# Output standards

A PAW deliverable should contain: objective; scope and assumptions; method; result; evidence register; confidence; limitations and unknowns; decisions; security/licence notes; tests and blocked checks; and handoff state.

Use concise headings and stable identifiers. Make outputs readable to non-programmers while retaining exact paths, versions, schema names, and commands for technical users. Do not hide a failed or blocked check inside a success summary.
