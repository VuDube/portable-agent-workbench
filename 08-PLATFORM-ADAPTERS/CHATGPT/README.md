# ChatGPT adapter

Baseline: paste the universal instructions into the conversation or a supported instruction field; attach relevant Markdown reference files; invoke one skill at a time; use only available tools and connected apps.

Do not make custom GPT creation a mandatory path. OpenAI's November 2026 documentation describes a custom GPT migration/retirement programme with dates and account/workspace-specific exceptions. Verify current account notices and migration options before relying on GPTs.

Official references:
- https://help.openai.com/en/articles/20001519-custom-gpt-retirement-and-migration-faq
- https://help.openai.com/en/articles/8554397-creating-and-editing-gpts
