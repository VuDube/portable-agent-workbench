# Prepare bounded process capture

**Capability tier:** T0/T1 planning; actual capture requires an authorized T3 environment.

## Procedure

Define target process, authority, time and resource ceilings, permitted observation channels, prohibited mutations, cleanup, cancellation, retention, and output limits. Obtain approval. Capture only the declared scope. Record partial results and cleanup status.

## Required output

Return a question statement, scope and authority record, ordered observations, evidence ledger entries, fact/inference/unknown separation, limitations, approvals, and a next-action handoff. A document-only run must say that no native analysis or runtime capture was executed.
