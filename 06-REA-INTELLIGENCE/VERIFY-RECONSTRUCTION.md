# Verify a reconstruction

**Capability tier:** T0/T1 can produce a verification plan; execution may be T2/T3.

## Procedure

State the reconstruction claim and the original observation it is meant to reproduce. Define an oracle and test inputs. Execute or manually inspect the bounded comparison if tools are available. Record mismatches, coverage, and residual unknowns. Never treat a plausible narrative as verification.

## Required output

Return a question statement, scope and authority record, ordered observations, evidence ledger entries, fact/inference/unknown separation, limitations, approvals, and a next-action handoff. A document-only run must say that no native analysis or runtime capture was executed.
