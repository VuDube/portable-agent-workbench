# Trace a crash

**Capability tier:** T0/T1 planning; runtime capture is optional T2/T3.

## Procedure

Define the crash signature, version, environment, trigger, and authority. Preserve logs safely and separate observed stack data from hypotheses. Reproduce only with approval and bounded side effects. Test candidate causes, record eliminated hypotheses, and report confidence and missing evidence.

## Required output

Return a question statement, scope and authority record, ordered observations, evidence ledger entries, fact/inference/unknown separation, limitations, approvals, and a next-action handoff. A document-only run must say that no native analysis or runtime capture was executed.
