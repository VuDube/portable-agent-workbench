# Compare application versions

**Capability tier:** T0/T1 baseline; runtime or binary tools are optional T2/T3 integrations.

## Procedure

Pin both versions and define comparison dimensions. Build a source and behaviour matrix. Capture version-specific observations, identify changed and unchanged behaviour, and distinguish missing coverage from absence. Record reproducibility limits and a conclusion only where evidence supports it.

## Required output

Return a question statement, scope and authority record, ordered observations, evidence ledger entries, fact/inference/unknown separation, limitations, approvals, and a next-action handoff. A document-only run must say that no native analysis or runtime capture was executed.
