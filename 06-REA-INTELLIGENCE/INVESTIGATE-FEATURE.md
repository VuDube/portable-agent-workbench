# Investigate a feature

**Capability tier:** T0/T1; T2 or T3 tools are optional and must be declared.

## Procedure

Describe the feature question and define target, scope, authority, and stopping conditions. Collect observations from permitted sources. Link each observation to a location and evidence ID. Separate observed behaviour from inference. Record unexamined branches and residual unknowns. Produce a bounded finding and verification plan.

## Required output

Return a question statement, scope and authority record, ordered observations, evidence ledger entries, fact/inference/unknown separation, limitations, approvals, and a next-action handoff. A document-only run must say that no native analysis or runtime capture was executed.
