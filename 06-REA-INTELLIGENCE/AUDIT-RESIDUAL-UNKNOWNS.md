# Audit residual unknowns

**Capability tier:** T0/T1.

## Procedure

Load the current evidence ledger and enumerate every unresolved question. Classify each by impact, coverage gap, and cost to resolve. Check whether any conclusion overstates the evidence. Prioritize bounded follow-up work and record accepted unknowns explicitly.

## Required output

Return a question statement, scope and authority record, ordered observations, evidence ledger entries, fact/inference/unknown separation, limitations, approvals, and a next-action handoff. A document-only run must say that no native analysis or runtime capture was executed.
